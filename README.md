A one-line error message an AI agent shows when it runs out of tokens
mid-sentence — entered in make.fun's "Out of Tokens, Mid-Sentence" bounty.
HTTP 402 is literally "Payment Required", so the unfinished sentence becomes
a vending machine: the rest of it costs 12 more tokens, insert coin to
continue.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (deterministic, offline, stdlib only).
